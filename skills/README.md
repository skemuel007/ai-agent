# Agent Continuation Skills

This folder contains handoff notes for another coding agent working in this repository.

Start here, then read the focused files as needed:

- `repo-map.md` - current repository structure and project responsibilities.
- `environment-setup.md` - how configuration, `.env`, and Azure authentication work.
- `development-workflow.md` - build, run, package, and git workflow notes.
- `continuation-notes.md` - current state, assumptions, and likely next steps.

These files are project-specific guidance, not executable code.
